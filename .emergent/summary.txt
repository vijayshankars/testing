1.  **Authentication**: Initially basic, upgraded to Google OAuth and then robust mobile OTP using Twilio for riders, drivers, and an admin user type.
2.  **Mapping & Location**: Implemented Google Maps for pickup/drop, route calculation, live tracking, and fare estimation. Refined with Google Places API for suggestions and local relevance (Chennai). Enhanced with vehicle-specific icons for drivers on the live map.
3.  **Payment Gateways**: Integrated Stripe for general payments and Razorpay for UPI, crucial for the Indian market.
4.  **Driver Features**: Allowed drivers to set per-km rates (later auto-assigned based on vehicle type), view nearby requests, receive notifications, and upload documents (driver's license, vehicle registration). Advanced to include VAHAN integration for license and vehicle number verification, and camera capture for document uploads.
5.  **Ride Management**: Functionality for requesting, accepting, canceling rides, viewing history, and OTP-based ride authentication. Enhanced ride cancellation with a confirmation popup and improved display of ride OTP to the rider.
6.  **Admin Dashboard**: A management interface for user management, later enhanced with a mobile number search feature.
7.  **Rider App Enhancements**: Implemented a comprehensive discount system with various discount types, a user-friendly UI for applying/viewing offers, and integration with fare calculation. The Book a Ride interface was refined to place the drop location at the top and auto-populate the pickup location with the user's current location.
